## 📖 Description

Beuitty is a responsive landing page created to showcase a beauty salon's services, introduce the team, and build customer trust through testimonials. The project focuses on a clean interface, engaging animations, and a smooth browsing experience across all devices.

---

## ✨ Key Features

- Responsive layout for desktop, tablet, and mobile devices.
- Animated page sections triggered on scroll.
- Interactive testimonials slider.
- Modern and intuitive UI.

---

## 🛠 Development

- Semantic HTML5 markup.
- Modular SCSS architecture.
- Custom Gulp build workflow.
- Responsive layout built with Flexbox.
- Optimized project structure.
- Cross-browser compatibility.
- Performance-oriented implementation.

---

## 🎯 Result

The final product is a fast, responsive landing page with smooth animations and interactive elements that effectively presents the beauty salon while providing an enjoyable user experience.
